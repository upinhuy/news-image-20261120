Entry for the make.fun bounty **"Sum up 20 November's world news in one image"**
(news-image-20261120, $250 USDC).

One 1024×1024 image with 50 sourced stories from Friday 20 November 2026:
three lead stories (Russian missiles breach Poland, the Nasdaq's 5.28% AI
rout, and the UK–EU reset deal sealed in Brussels) plus a 47-story timeline,
hour by hour in UTC, each with its source. Sources include Reuters, BBC, AP,
Financial Times, ESPN, Formula1.com, CoinDesk, WHO, ATP Tour and more.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` into the output directory and verifies the copied
file has the same byte count as the source.
